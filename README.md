# Saytqtul

일기장 사이트를 만들어 보고 싶어
처음 들어가면 일기장이라는 큰 글씨가 있고 그 밑에 '적으러 가기' 버튼이 있으면 좋겠어
그리고 그 버튼을 누르면 달력이 나와 있고 날짜를 누르면 글을 쓰고 이전에 쓴 글을 읽을 수 있도록 하면 좋겠어
이전에 쓴 글을 수정할 수도 있고 내가 댓글을 달 수도 있어
이건 로그인을 해야 접근할 수 있어
